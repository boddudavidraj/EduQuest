Q: What is Object-Oriented Programming (OOP)?

OOP is a paradigm based on "objects", which contain data and methods. Key principles are Inheritance, Encapsulation, Polymorphism, and Abstraction.

Q: Difference between pointer and reference in C++?

Pointers store addresses and can be reassigned or null. References are aliases, cannot be reassigned, and cannot be null.
