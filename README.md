# EduQuest
# 🚀 Placement Preparation & Resume Builder Platform

An interactive web-based placement preparation platform designed to help students improve their aptitude skills, prepare for technical interviews, and create a basic resume based on their technical skills and projects.

## 📌 Project Overview

The Placement Preparation Platform provides students with multiple tools to prepare for campus placements in an interactive and user-friendly way.

The platform includes:

* 🧠 Aptitude Question Practice
* 💻 Technical Interview Questions
* 📄 Resume Builder
* 📊 Interactive Feedback
* 🎯 Student Placement Preparation Features

---

## ✨ Features

### 🧠 Aptitude Practice

Students can answer aptitude questions through interactive buttons.

The system:

* Displays multiple-choice options
* Checks the selected answer
* Shows instant feedback
* Identifies correct and incorrect answers

Example:

```text
Question: What is the shortest distance between two points?

Options:
• 324 meters
• 180 meters
```

---

### 💻 Technical Interview Preparation

The platform includes commonly asked technical interview questions.

Currently included topics:

#### Object-Oriented Programming (OOP)

OOP is a programming paradigm based on objects that contain data and methods.

The four major principles are:

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

#### Pointer vs Reference in C++

| Pointer                    | Reference               |
| -------------------------- | ----------------------- |
| Stores a memory address    | Acts as an alias        |
| Can be NULL                | Cannot normally be NULL |
| Can be reassigned          | Cannot be reassigned    |
| Uses `*` and `&` operators | Uses `&`                |

---

### 📄 Resume Builder

Students can enter:

* Technical Skills
* Major Projects

The platform then generates a simple resume preview.

Example:

```text
==============================
          RESUME
==============================

TECHNICAL SKILLS:
C, C++, Python, HTML, CSS

MAJOR PROJECTS:
E-Commerce Website, Chat Application
```
